# Logistics Data Analysis

This repository contains my internship project on logistics data analysis using Python and data science techniques.

## Project Overview

The project focuses on delivery route optimization and late-delivery prediction for a logistics company.

The main goals are:

- Analyze logistics and delivery data
- Identify factors affecting delivery delays
- Calculate important logistics KPIs
- Predict late deliveries
- Analyze customer and route patterns
- Explore route optimization techniques
- Provide data-driven recommendations

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook
- Data Analysis
- Machine Learning
- Optimization
